Privacy Policy — Gmail Triage

Last updated: October 18, 2026

Gmail Triage is a personal tool used only by its author (Changwoo Lim) on the author's own Gmail account. It is not offered to the public and has no other users.

Data accessed

Through the Gmail API (scope https://www.googleapis.com/auth/gmail.modify) the app reads the sender, subject, labels and message ID of recently received messages. It does not read message bodies or attachments.

How the data is used

  • Sender and subject are sent to the OpenRouter API (Perplexity Decider model) to score whether each message should be kept or is a delete candidate.
  • The resulting summary is sent to the author's own private Telegram chat.
  • When the author approves, the app moves the approved messages to Gmail's Trash. It never permanently deletes mail and never sends, forwards or modifies the content of any message.

Storage and sharing

The OAuth token and a short list of the latest delete candidates (message ID, sender, subject, score) are stored on the author's private server with owner-only file permissions. Records older than 14 days are discarded. No data is sold, used for advertising, or shared with anyone other than the processing services named above.

Google API Services User Data Policy

Gmail Triage's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
